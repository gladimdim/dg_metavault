**GladRoTools** is committed to protecting your privacy. This policy describes how the application handles information when you use GladRoTools on macOS.

## Data Collection

GladRoTools does **not** collect, store, or transmit any personal information. The application does not require account registration and does not request access to your name, email address, location, contacts, or any other personally identifiable data.

## Data Storage and Processing

All data processed by GladRoTools remains **exclusively on your device**. This includes:

- Place and asset metadata retrieved from Roblox Studio.
- Cached asset thumbnails and file data.
- Diagnostic logs generated by the application.
- Scan history and analysis results.
- Roblox OAuth access and refresh tokens (stored in the Application's local secure storage).

No user data is uploaded to any server operated by the developer. No data is transmitted to third-party analytics services, advertising networks, or tracking platforms.

## Roblox Open Cloud API Key

Certain features of GladRoTools require a Roblox Open Cloud API key, which you provide at your discretion. This key is **stored locally on your device** and is transmitted exclusively to Roblox's official API endpoints (`apis.roblox.com`) for the following purposes:

- Reading asset metadata and retrieving asset binary data.
- Creating or modifying assets within your Roblox experience.
- Verifying asset permissions and inventory access.

The API key is never sent to any server other than Roblox. The developer does not have access to your API key at any time.

## Network Communication

GladRoTools performs network requests in the following limited circumstances:

| Destination | Purpose | Data Transmitted |
|---|---|---|
| Roblox CDN (`*.rbxcdn.com`) | Fetching asset thumbnails | Asset identifiers |
| Roblox Open Cloud (`apis.roblox.com`) | Asset read, write, and management operations | API key, asset identifiers, asset data |
| Roblox OAuth (`apis.roblox.com`) | OAuth 2.0 authentication, token exchange, and token refresh | Authorization codes, OAuth access and refresh tokens |
| Apple (`*.apple.com`) | Verifying App Store subscription receipts | Encrypted receipt data |

No data is sent to any server owned or operated by the developer.

## Diagnostics and Logging

The application writes diagnostic logs to your local file system for troubleshooting purposes. These logs are stored on your device and are never automatically transmitted. Logs are only shared if you manually export and send them to the developer for support purposes.

## Subscription and Payments

Subscription management and payment processing for **GladRoTools Pro** are handled entirely by Apple through the Mac App Store. The developer does not receive or process your payment information. Receipt validation is performed by communicating directly with Apple's verification servers.

## Third-Party Services

GladRoTools does **not** integrate any third-party analytics, crash reporting, advertising, or tracking services. The application does not use cookies, device fingerprinting, or any form of user tracking.

## Changes to This Policy

This privacy policy may be updated from time to time. Material changes will be communicated through the application or the Mac App Store listing. Continued use of the application after changes constitutes acceptance of the revised policy.
